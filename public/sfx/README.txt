Drop your sound files here. Any file that is missing falls back to a built-in synthesized sound,
so the game always has audio. Use .mp3 with exactly these names:

  shake.mp3     paper being rattled (about 0.8 s)
  toss.mp3      chits landing on the table (short)
  drumroll.mp3  suspense build-up (about 2.6 s, ends just before the verdict)
  stamp.mp3     badge slam / rubber stamp thud
  crinkle.mp3   paper crumpling
  whirr.mp3     film projector (about 1.4 s)
  bgm.mp3       soft background music, loops
