Optional: put your own reaction images in the folder for each moment. One is chosen at random.
With no image, the game shows an old-film title card with an icon instead.

  police_reveal/   the police is revealed
  caught/          the thief was caught
  wrong_accuse/    police accused the wrong person
  escaped/         the thief got away
  king_reveal/     the winner
  last_place/      last place

.jpg .png .webp .gif accepted. The list is rebuilt on `npm run dev` / `npm run build`.
Only use images you have the right to publish.
